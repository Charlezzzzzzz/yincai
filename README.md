# 因才

面向任课教师的六智能体备课工作台。以一道一元一次方程为例，教师可以从班级错因走进一份教案，读到核查员退回的原句，翻看同段修订，再亲自决定如何讲。六个岗位的独立头像与可旋转 3D 模型贯穿协作圆桌和对话。任课教师有两款可选造型，共享同一套决策权限。

![因才的教研工作簿与六个岗位](cover/studio.webp)

## 在本机运行

使用 Python 3.11 或更新版本，建议 3.12。先下载发行版源码并解压，也可以克隆仓库。在项目根目录执行以下命令。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./start.command
```

在浏览器打开 `http://127.0.0.1:8772/`。Windows 可用 `py -3.12 -m venv .venv` 建立环境，再依次运行 `.venv\Scripts\python -m pip install -r requirements.txt` 和 `.venv\Scripts\python serve.py`。服务只监听本机。若端口已占用，可用 `./start.command --port 8783` 指定另一端口。

## 体验一次教师备课

1. 从工作簿进入协作圆桌，选择「核查退回」。在教案原句旁阅读退回理由，再选择「修订」「复核通过」比对同一段的前后版本。
2. 在「模型设置」选择服务、填写自己已开通的模型 ID 并保存。返回对话，点学情分析师头像提问。收到回复后，教师可点「请学科专家接续」，由专家读取这次明确转交的内容。模型服务失败时，页面保留错误与待处理的问题。
3. 进入教师批阅。三名模拟学生的建议初始均为待定，教师逐条采纳、原位修改或否决。保存教师稿后可刷新读回本机 SQLite。学生研习页只展示教学样例，教师审阅没有自动发布操作。

### 模型服务与演示模式

模型设置支持本机 Ollama 和提供兼容 Chat Completions 文本接口的云服务。页面提供厂商预设、可编辑的模型 ID 与自定义接口。可用模型与地域取决于本人账号及厂商。远端接口使用 HTTPS。常规模式下「测试连接」会发出一次真实请求。用已有额度进行演示时，在新标签打开 `http://127.0.0.1:8772/?recording=1#settings`，在私密弹窗输入密钥并保存，再切换到岗位对话。录制模式在同一标签限制两次发送，失败后暂停。一条教师提问和一次亲自点击的岗位转交各计一次。

网页填写的密钥只在当前后端进程内存中生效，重启服务后需重新配置。教师审阅和对话回执写入本机数据库。首次体验可用 `--db` 指定程序目录之外的新 SQLite 文件。默认路径在 macOS 的 `~/Library/Application Support/因才/reviews.sqlite3`，在 Linux 的用户数据目录和 Windows 的本机应用数据目录下也有对应文件。

### 课堂资料和教研回复

在任一岗位的消息输入框选择附件，可以先检查文档名称或图片缩略图，逐件移除。发送前页面展示接收模型。每条消息最多 3 份，每份不超过 3 MiB，合计不超过 6 MiB。

| 资料 | 处理方式 |
| --- | --- |
| UTF-8 的 TXT、Markdown、CSV | 服务端提取正文，并标明是教师提供的参考资料。 |
| DOCX、带文字层的 PDF | 提取可选取的正文。扫描版 PDF 没有文字层时会提示更换资料。 |
| PNG、JPEG、WebP | 服务端移除元数据并按需缩放，以图像随本轮请求发送。云端读图需要所选模型支持多模态输入。 |

教师点击发送时，文档提取的文字或图像会交给当前模型。原文件只保留在标签页内存；SQLite 保存文档提取文本、附件摘要及会话回复，供本机继续追问。刷新后，尚未送出的文件需要重新选择或移除。教师将一条回复交给其他岗位时，该岗位收到的是那条已选回复。

对话气泡在本机排版加粗、列表、引用、表格和代码。用美元符号或 TeX 括号标注的方程由 KaTeX 转为 MathML。先前储存的纯文本回复也能使用同一排版。显示历史记录时页面保留历史来源和原始生成耗时。

## 如何读证据

| 标记 | 页面含义 |
| --- | --- |
| ● 实时生成 | 本次对话收到上游返回的文本，回执展示厂商、模型及耗时。 |
| ○ 真实缓存 | 先前生成的内容或历史会话。小川案例的八步模型缓存合计 526.8 秒，单次新对话独立计时。 |
| □ 模拟或规则 | 30 名模拟学生、错因分类和岗位路由。前三类错因合计 23 名学生。 |

八步依次为诊断、校验、设计、初稿、核查退回、修订、复核通过、交付。它们由学情分析师、学科专家、教学设计师、多模态制作人、核查员和教师助理承担。第 12 题 `(x−1)/2−(x+2)/3=1` 的解为 13。初稿直接暴露答案的句子用于演示核查退回。小川、小禾、小远是教学样例中的三名模拟学生。小远第三段微课的旁白与公式仍待核验。公开版提供小川、小禾两段带字幕的无声微课。
